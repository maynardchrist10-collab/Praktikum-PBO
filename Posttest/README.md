Program ini merupakan Sistem Manajemen Presensi Karyawan yang dibuat menggunakan konsep Pemrograman Berorientasi Objek (PBO). Program memiliki tiga class utama, yaitu Karyawan, Presensi, dan ManajemenPresensi. Class Karyawan digunakan untuk menyimpan informasi karyawan seperti nama, ID, jabatan, dan gaji pokok. Class Presensi digunakan untuk mencatat data kehadiran karyawan berdasarkan tanggal dan jam masuk, sedangkan ManajemenPresensi digunakan untuk mengelola dan menampilkan kumpulan data presensi berdasarkan departemen.

Program ini menerapkan atribut kelas dan atribut instance. Atribut kelas digunakan untuk menyimpan data yang digunakan bersama, seperti nama perusahaan, jam masuk standar, dan jumlah karyawan. Sementara itu, atribut instance digunakan untuk menyimpan data yang berbeda pada setiap objek, seperti nama, ID, jabatan, dan gaji masing-masing karyawan. Program juga menerapkan encapsulation dengan membuat beberapa atribut penting menjadi private menggunakan tanda __, seperti __gaji_pokok, __jam_masuk, dan __daftar_presensi.

Untuk mengakses atribut private tersebut, program menggunakan property, getter, dan setter. Getter digunakan untuk mengambil nilai atribut private, sedangkan setter digunakan untuk mengubah nilainya sekaligus melakukan validasi. Contohnya, gaji pokok tidak boleh memiliki nilai kurang dari atau sama dengan nol, sedangkan jam masuk harus menggunakan format waktu yang valid. Dengan adanya validasi tersebut, data yang tidak sesuai dapat ditolak sehingga data dalam program tetap terkontrol.

Program juga menerapkan tiga jenis method, yaitu instance method, class method, dan static method. Instance method digunakan untuk mengolah atau menampilkan data dari objek, class method digunakan untuk mengubah atribut kelas atau membuat objek dengan cara tertentu, sedangkan static method digunakan sebagai fungsi bantuan seperti validasi ID karyawan dan perhitungan keterlambatan.

Pada bagian presensi, program dapat menentukan apakah seorang karyawan tepat waktu atau terlambat dengan membandingkan jam masuk karyawan dengan jam masuk standar perusahaan. Program menghitung selisih waktu dalam satuan menit sehingga dapat diketahui jumlah keterlambatan. Seluruh data presensi kemudian dapat dimasukkan ke dalam ManajemenPresensi untuk ditampilkan sebagai rekap kehadiran.

Secara keseluruhan, program ini menunjukkan penerapan konsep Class & Object, Atribut & Method, serta Encapsulation & Property dalam sebuah sistem presensi karyawan. Program tidak hanya menyimpan dan menampilkan data, tetapi juga memberikan validasi terhadap data yang dimasukkan sehingga penggunaan konsep PBO dapat terlihat dalam pengelolaan data karyawan dan presensi.
